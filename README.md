# world-video-games-final-data-analyst

## project overview
World Video Game Industry Analysis adalah project analisis data yang bertujuan untuk memahami perkembangan industri video game berdasarkan tahun rilis, genre, dan platform.

Project ini menggunakan dataset yang berisi informasi mengenai judul video game, tanggal rilis, platform, dan genre. Analisis dilakukan menggunakan Python dan Pandas untuk proses data cleaning serta exploratory data analysis (EDA), kemudian hasil analisis divisualisasikan untuk menemukan pola dan tren dalam dataset.

## bussiness problem
Industri video game terus berkembang dengan munculnya berbagai genre dan platform. Perubahan tersebut dapat memberikan gambaran mengenai perkembangan dan tren industri video game dari waktu ke waktu.
1. Bagaimana perkembangan jumlah game yang dirilis dari tahun ke tahun?
2. Genre apa yang paling banyak digunakan?
3. Platform apa yang paling banyak digunakan?
4. Bagaimana perkembangan genre dari waktu ke waktu?
5. Bagaimana perkembangan platform dari waktu ke waktu?

Oleh karena itu, project ini dilakukan untuk menganalisis data video game dan menemukan pola berdasarkan release year, genre, dan platform.

## data cleaning
Beberapa proses data preparation yang dilakukan dalam project ini meliputi:

1. Memeriksa struktur dataset.
2. Memeriksa missing values.
3. Memeriksa duplicate data.
4. Mengubah release_date menjadi format datetime.
5. Membuat kolom release_year berdasarkan tanggal rilis.
6. Memisahkan multiple genres menggunakan split() dan explode().
7. Memisahkan multiple platforms menggunakan split() dan explode().

## key insight
1. Tahun dengan jumlah perilisan game tertinggi.
2. Genre dengan jumlah game terbanyak.
3. Platform dengan jumlah game terbanyak.
4. Perubahan popularitas genre dari waktu ke waktu.
5. Perubahan penggunaan platform dari waktu ke waktu.
